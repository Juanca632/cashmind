# Quickstart: Rename Entries

```bash
npx jest --maxWorkers=4
npx tsc --noEmit
npx expo lint
npm run demo
```

In demo mode on the emulator:

1. Home shows the same figures as before; tap an entry: the entry screen opens.
2. Add, edit and delete an entry: works as before, same texts.
3. Pick a past month and back: same figures.

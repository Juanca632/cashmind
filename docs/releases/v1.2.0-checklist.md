# v1.2.0 release checklist

v1.2.0 brings `015-categories`, `016-design-tokens` and `017-entry-and-daily-budget` (PR #7). AGENTS.md requires an end-to-end run on a real device before any APK. This release migrates the stored data (step 6 adds `entry.category`) and adds a native module (`@react-native-community/datetimepicker`), so do not skip it.

Run it with the `e2e-tester` subagent (Android emulator or phone with `adb`), or by hand: `npx expo start` and Expo Go for steps 2–6, the installed APK for step 1. The detailed steps are in each feature's `quickstart.md`:

- [specs/015-categories/quickstart.md](../../specs/015-categories/quickstart.md)
- [specs/016-design-tokens/spec.md](../../specs/016-design-tokens/spec.md) (acceptance scenarios; no quickstart)
- [specs/017-entry-and-daily-budget/spec.md](../../specs/017-entry-and-daily-budget/spec.md) (acceptance scenarios)

## Checks

- [ ] **1. Upgrade keeps the data** (APK only): install v1.2.0 over v1.1.0 on a phone with data. Every entry keeps its amount, date, kind and note, is in Other, and rows look as before ("Expense" for an entry without a note).
- [ ] **2. Categories**: the form shows the kind's categories with Other selected; switching kind selects Other again; saving and reopening keeps the category; tapping Spent, Income or Savings on home shows "By category" (650 / 320 / 230 € expenses give 54 / 27 / 19 %).
- [ ] **3. Daily budget**: in the current month the card shows "≈ X / day · N days left", or "Today: X" on the last day; nothing in a past month, without income, at 0 or when overspent.
- [ ] **4. Date picker**: tapping the date opens Android's calendar on the form's date, limited to the entry's month and to today; cancelling keeps the date; ‹ › still move one day.
- [ ] **5. Entry form**: the note example is Cinema / Salary / Emergency fund for expense / income / savings; no description under the kind choices.
- [ ] **6. Look**: pills, "See all" and dialogs show no wrapped text; buttons, action pills and the kind tiles have a soft shadow, the month card a green halo (red when overspent); scrolling content fades under the system bars with 3-button and with gesture navigation; light and dark mode both look right.

## Then

When every check passes: `npx eas-cli build --platform android --profile production` (check the EAS plan's build quota first), install the APK on the phone and tick check 1 there.
